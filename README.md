# DIGITAL-MARKETING
Project Title: On-Page SEO Optimization for E-commerce Website
Role: SEO & Paid Media Intern

🎯 Objective:
To enhance the website’s organic visibility and increase qualified traffic by implementing on-page SEO strategies tailored to e-commerce best practices.

🔍 Key Responsibilities:
Website Audit:

Conducted comprehensive SEO audits using tools like Screaming Frog, SEMrush, and Google Search Console to identify existing on-page issues.

Evaluated crawlability, indexability, and overall technical health of the site.

Keyword Research:

Performed keyword analysis targeting high-volume, low-competition queries using Ahrefs and Google Keyword Planner.

Mapped primary and LSI keywords to relevant product/category pages for improved targeting.

Content Optimization:

Optimized product titles, meta descriptions, headers (H1, H2), and product descriptions with relevant keywords.

Structured content using SEO-friendly formats to improve readability and relevance.

Image SEO:

Compressed and renamed product images with keyword-rich filenames and added descriptive alt tags for better accessibility and image search ranking.

Internal Linking:

Built strategic internal links between category pages and blog content to enhance crawl depth and user navigation.

URL & Schema Optimization:

Ensured clean, descriptive URLs with proper keyword inclusion.

Integrated Product Schema Markup (JSON-LD) for enhanced rich snippets on search results.

Performance Monitoring:

Tracked changes in organic traffic and keyword rankings using Google Analytics and Search Console.

Delivered weekly reports to showcase progress and insights to the client.

📈 Outcome:
Improved organic traffic by 38% within 6 weeks.

Increased the number of top-10 keyword rankings by 22%.

Reduced page load time by 1.5 seconds, positively affecting SEO and user experience.

Enhanced visibility of product pages through rich snippets in Google SERPs.

🧰 Tools & Technologies:
SEMrush, Google Search Console, Ahrefs, Screaming Frog, Google Analytics, Canva (for banners & visuals), HTML, JSON-LD, Excel (for audits and reporting)
